# 제출 기록

공식 평가에 낸(또는 낼) ZIP과 그날 무엇을 했는지를 날짜별로 적는다. 하루 1회 공식 평가라서 **ZIP 하나 = 하루 한 줄**이 기본.

- ZIP 이름: `YYYY-MM-DD_버전.zip` (`python make_zip.py --save v0.9` 로 생성·복사됨)
- ZIP 내용: `run.py`, `requirements.txt`, `nova_sdk.py`, `agent/` 만. 개발 키·자료 폴더는 절대 안 들어간다(생성 시 자동 검사).
- 제출 방법: 대회 사이트 → 공식 평가 → ZIP 업로드. 업로드는 사람이 직접 한다.
- 점수 표기: "로컬"은 `bench/grade.py`의 근사 채점(샘플 3건, 버전 비교용). "공식"은 사이트 결과. 공식 결과가 나오면 그날 항목에 추가로 적는다.
- 상세 변경 내역은 `docs/CHANGELOG.md`, 논문 근거는 `docs/RESEARCH.md`.
