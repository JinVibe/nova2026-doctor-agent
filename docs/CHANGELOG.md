## v1.5 — 최종 진단 안정화 (10/14 밤, 로컬 반복 실행으로 검증)
- 발견: 같은 코드로 C03을 5번 돌리면 2번이 성장호르몬 결핍증 오답(v1.1·v1.4 오답도 같은 원인). 다섯 번 모두 사실·반대 의견이 거의 같았고
  (반대 의견은 늘 "중간부모키 178cm인데 3백분위 미만 → 체질성과 어긋남"), REASSESS가 확률적으로 그 의견을 따라감.
- REASSESS: diagnosis 전에 상위 2~3 후보마다 `candidates[{dx, for, against}]`를 **기록에 있는 사실로만** 쓰게 함. 진찰 수치 우선(검토 의견이 스스로
  계산한 수치가 다르면 진찰 수치), 수치가 정상인데 그 이상이 핵심인 진단은 주진단 금지, "유전 목표와의 차이·배제 검사 없음"은 반대 사실이 아니라 검사 계획 이유.
  소아 저신장 원칙 추가(성장속도 정상 + 신체 비율 정상 + 부모의 늦은 성장 → 체질성 지연 우선; 병적 원인은 성장속도 저하나 해당 소견이 있을 때).

## v1.2 — 진단 안정화·기록 정직성 (10/14 제출 후보)
- REASSESS: "배제되지 않은 위험 진단"은 검사 계획·r/o의 이유일 뿐, 뒷받침 사실 없이 주진단을 더 드물고 위험한 진단으로 바꾸지 않음

- RECORD: "안내함·설명함"은 실제 마무리 설명에 있는 말에만; 하지 않은 안내는 "안내 예정"으로(세 증례 모두 감점받던 항목).
- CLOSING: 진단은 "~일 가능성이 높아 보입니다"로(검사 전 단정 감점). 환자 질문 답이 30자를 넘으면 기본 답으로 대체(C01에서 답 못 한 버그).
- VERIFY: 숫자는 아라비아 숫자·표준 단위로(v1.1이 "오십육 키로그람"처럼 말소리로 바꿈), 형식 줄 유지, 환자의 걱정·요구 누락 시 보충.
- 공통 진찰에서 활력징후 측정 제거(첫 진술에 이미 있어 "재측정" 감점). 공통 진찰 = 전반 외관·심음·폐.
- `agent/config.py` 스위치(USE_GUIDELINES, VERIFY_S, CORE_EXAMS_FULL) + `make_zip.py --candidate --set` 으로 사이트 샘플 검증 A/B.
- 증례당 5.5~6.5분, Doctor 호출 8~11회(재계획 증가). 채점기가 호출 수를 효율 감점 사유로 언급 → 다음 과제.
