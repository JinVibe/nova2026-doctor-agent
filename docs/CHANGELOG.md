## v0.9 — 진단추론 안정화·안전·안정성 (논문 적용: docs/RESEARCH.md #2·#3·#6)
- CHALLENGE 단계(MAI-DxO Dr. Challenger): 1위 진단의 모순·설명 안 되는 소견·배제 안 된 위험 진단을 점검하고,
  판가름 질문(≤3)·진찰(≤2)을 남은 턴에 실행 → REASSESS가 이 검토 의견을 반박·수용한 뒤 최종 진단.
- REPLAN에 확신도(1~5)·부족 정보 출력(MediQ): 확신 4 이상이면 질문 중단. 질문은 1위 vs 2·3위를 가르는 대조 질문 우선(MedClarify).
- 주진단 정리: "의심·잠정·가능성·괄호 설명" 제거(판정은 진단명 비교).
- 안정성: `INVALID_API_RESPONSE`(게이트웨이 HTML 응답) 재시도 추가, PROVIDER_UNAVAILABLE·REQUEST_PENDING은 같은 request_id로 재시도(문서 지침),
  대기 2·5·10·20·30초, `session()` 호출도 재시도. 실제로 v0.9 첫 실행에서 C01이 `session()`의 INVALID_API_RESPONSE로 중단된 적 있음.

## v0.8 — 정보수집(소아)·의사소통
- 소아(첫 진술에 보호자·아이) 감지 → 흡연·음주·직업 대신 출생·발달·예방접종·"부모님도 어릴 때 비슷했는지"·학교생활.
- 마무리 설명 뒤 환자가 되물으면 최대 2턴 답변(`ANSWER_PROMPT`).
- 계획: 첫 진술에 있는 사실 재질문 금지. 재계획: 일부만 답한 질문은 쪼개 다시, 진단 관련 가족력 구체화.

## v0.7 — 검사·추적·안전·의사소통
- P.tests: 확진·중증도 / 감별 배제 / 기본 혈액 / 필요 시 심전도·영상·선별 척도를 빠짐없이. 재진 시점 구체화.
- 안전: 주진단 관련 구체 위험(급중단·병용·과량·낙상·운전)과 대처를 P에.
- 마무리 설명 6 → 8줄(공감, 피해야 할 것, 구체 응급 경고, "궁금한 점 있으세요?"). 턴 상한 48.
- 공통 진찰에 활력징후 측정(3개 샘플 진찰표 공통 행) 추가.

## v0.6 — 진단추론 (Sequential Diagnosis / MAI-DxO의 가설 갱신 아이디어)
- REASSESS 단계: 진료 전체를 다시 읽고 최종 주진단 결정 → 마무리 설명·기록이 이를 따름.
- DX_RULES: 증상명보다 원인 진단, 약물·물질 원인 항상 검토, 내원 요구(처방 요청 등) 자체를 단서로.
- 과거력 문진 직후 재계획 1회(약 용량·금단·감량 실패·다중 처방 등 MED_RULES 후속 질문을 진찰 전에).
- 음주 문진 누락 버그 수정("수술"에 "술" 포함), 거절된 "신체 계측" 진찰 삭제, 턴 상한 40 → 46.
