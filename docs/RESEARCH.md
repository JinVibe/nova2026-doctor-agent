# 참고 논문 → 우리 에이전트 적용표

2026-10-13 deep-research 결과(출처 23개, 주장 25개를 3표 교차 검증, 22개 확인·3개 기각)를 우리 파이프라인 기준으로 정리.
효과 크기는 대부분 **저자 자체 보고·시뮬레이션 OSCE·미세조정 모델** 기준이다. 고정 LLM(gpt-6-luna)인 우리는 **구조만** 가져오고, 효과는 로컬 벤치로 직접 확인한다.

## 남은 질문
- 위 기법들의 단독 효과(고정 LLM, 50턴·30자 조건)는 논문에 없음 → 로컬 벤치 ablation으로 확인.
- self-consistency(여러 번 진단 후 투표) vs challenger 1회 중 무엇이 더 안정적인가, 호출 비용 대비.
- 확신도 종료 임계값(MedClarify Pmax>0.97, g-AMIE "높은 확신 또는 턴 상한").

## 10/16 심층 조사 — "지금 기준에서 최선"을 축별로 (deep-research, 1차 문헌 21편, 105개 주장 중 25개 교차검증 → 17개 확정·8개 반박)

**한 줄 결론.** 고정 모델·50턴·30자 제약에서 점수를 올리는 핵심은 "질문을 더 많이"가 아니라 (1) 감별진단에 근거해 다음 질문의 목적을 명시하는 가설 주도 문진, (2) 조기확정 방지, (3) 응급 경고·약물 안전·재방문 시점·공감을 기록이 아닌 **대화 발화**로 실제 수행하는 것. 턴을 늘려도 진단은 좋아지지 않는다(AgentClinic 20→30턴에서 52%→43%, AMIE 10턴 내 plateau). v1.6(일반 체크리스트 추가 → 공식 −2)이 이 결론과 정확히 일치한다.
