# 채점 축별 전략

> PRD v0.2의 결정(D1~D11)을 채점 6개 축 기준으로 다시 묶은 문서. 각 축마다 **무엇을 잃고 있나 → 어떻게 따나 → 어디서 구현하나 → 어떻게 확인하나** 순서.
> 기준점: 기본 에이전트 C01 = 41.2점 (정보수집 3.8 · 진단추론 4.2 · 검사·추적 0 · 안전 11.3 · 의사소통 2.0 · 효율 20)

## 우선순위

| 순위 | 축 | 배점 | 기본 에이전트 | 잃는 점수 | 근거 |
|---|---|---|---|---|---|
| 1 | 정보수집 | 25 | 3.8 | **21.2** | 가장 크게 잃고, 코드로 통제 가능한 부분이 많음 |
| 2 | 의사소통 | 15 | 2.0 | **13.0** | 설명 SAY를 30자 단위로 쪼개기만 해도 회복 |
| 3 | 검사·추적 | 10 | 0 | **10.0** | P 칸 템플릿으로 바로 회복 |
| 4 | 진단추론 | 15 | 4.2 | 10.8 | 모델 능력 의존 → 정보수집이 오르면 따라 오름 |
| 5 | 안전 | 15 | 11.3 | 3.7 | 이미 높음. red-flag 질문·응급 교육으로 유지 |
| 6 | 효율 | 20 | 20 | 0 | **지키기만** — 중복 질문·진찰 거절 0, 턴 상한 |

## 1. 정보수집 (25) — 물어보고, 진찰하고, **기록까지**

**잃는 이유:** 결정적 단서(졸피뎀 용량)를 듣고도 기록 누락 · FH/ROS 빈칸 · 진찰 10번 중 6번 거절 · 채점은 기록 문장을 *글자 그대로* 인용

| 전략 | 구현 |
|---|---|
| 필수 문진 체크리스트를 코드가 보장 (과거력·약·수술·알레르기·가족력·흡연·음주·직업) | `agent/knowledge.py` `CORE_HISTORY`, 이미 다룬 주제는 키워드로 건너뜀 |
| 현병력·감별 질문은 LLM 계획(PLAN)으로 8~14개 | `agent/prompts.py` `PLAN_PROMPT` |
| 약은 이름·용량·횟수까지 후속 질문 | `REPLAN_PROMPT` 지시 |
| 진찰은 **어휘집 ID만** 선택 → 거절되지 않는 구체적 문구로 전송 | `agent/knowledge.py` `EXAMS` |
| O.exam은 LLM이 아니라 **코드가 진찰 로그에서 턴 번호와 함께 작성** | `agent/record.py` |
| S 칸은 숫자·용량·기간을 원문 그대로, 부정한 항목은 (-) | `RECORD_PROMPT` 규칙 |

**확인:** 모의 증례에서 체크리스트 커버리지 100%, 진찰 거절 0회, 환자 답변 속 숫자가 기록에 남았는지

## 2. 의사소통 (15) — 실제로 **말해야** 점수

**잃는 이유:** 설명이 30자를 넘어 재질문 반복 → 설명 미전달. 친절도는 별도 모델이 대화 원문으로 평가

| 전략 | 구현 |
|---|---|
| 첫 질문에 공감 한마디("많이 불편하셨겠어요.") | `agent/doctor.py` 첫 SAY |
| 마무리 설명 5~6턴: 진단 → 근거 → 검사 → 치료·생활 → 응급 경고 → 재방문 | `CLOSING_PROMPT` + 30자 검증 + 템플릿 폴백 |
| 모든 질문은 존댓말·쉬운 말·질문 하나 | 프롬프트 규칙 + `?` 2개 이상이면 제외 |
| 말한 설명은 P.education에 그대로 남김 | `agent/record.py` |

**확인:** 마무리 SAY가 매번 5턴 이상 성공, 30자 초과로 버려지는 비율

## 3. 검사·추적 (10) — P 칸을 구체적으로

**잃는 이유:** P 계획이 막연함 (예선은 TEST 행동이 없어 *계획*으로 평가받음)

| 전략 | 구현 |
|---|---|
| P.tests: 감별진단을 가르는 구체적 검사명 | `RECORD_PROMPT` |
| P.follow_up: 재방문 시점(예: "2주 후 외래")과 재평가 항목 | `RECORD_PROMPT` + 마무리 설명과 일치 |
| P.disposition: 귀가/입원/전원/응급 중 하나 명시 | `RECORD_PROMPT` |

**확인:** P 5칸 빈칸 0, 마무리 설명과 기록 계획의 일치

## 4. 진단추론 (15) — 감별진단을 끝까지 들고 간다

**잃는 이유:** 단서를 듣고도 흔한 진단(불면증)으로 수렴. 진단은 5점 척도(Nori et al.)

| 전략 | 구현 |
|---|---|
| PLAN에서 감별진단 3~5개(위험 질환 포함) → REPLAN마다 확률 갱신 | `PLAN_PROMPT`, `REPLAN_PROMPT` |
| 질문은 "1위 확정 또는 위험 질환 배제"에 필요한 것만 | `REPLAN_PROMPT` |
| A.evidence는 기록 속 사실을 인용, A.differential은 "r/o 진단 : 이유" | `RECORD_PROMPT` |
| (실험) 최종 진단 다수결 | 벤치로 이득 확인 후 |

**확인:** 공개 샘플 3건 + 합성 증례의 주진단 일치율

## 5. 안전 (15) — 위험 신호와 응급 교육

| 전략 | 구현 |
|---|---|
| PLAN 질문에 위험 신호 확인 포함 | `PLAN_PROMPT` |
| 마무리에 "이런 증상이면 바로 응급실" 경고를 반드시 말함 | `CLOSING_PROMPT` 4번째 항목 |
| 확신 없는 약물 처방 금지, 용량 조정은 "단계적 감량" 같은 안전한 표현 | `RECORD_PROMPT` |
| (다음 단계) 주호소별 red-flag 표 | `agent/rules` (D4) |

## 6. 효율 (20) — 잃지 않기

| 전략 | 구현 |
|---|---|
| 턴 상한 40(마무리 6턴 포함), 시간 여유 4분 남기고 마무리 | `agent/doctor.py` `TURN_BUDGET`, `TIME_MARGIN` |
| 같은 질문 재전송 금지, 진찰 ID 중복 금지 | `Visit.asked`, `exams_done` |
| 거절 0을 목표로 어휘집만 사용 | `EXAMS` |
| LLM 호출: PLAN 1 + REPLAN ≤3 + 마무리 1 + 기록 1 ≈ 6회 (기본 에이전트 37회) | `agent/doctor.py` |
| temperature 미전송(Doctor가 gpt-6-luna) | `agent/llm.py` |

**확인:** 턴 예산 30/35/40/45 스윕 후 효율 점수 변화

5. red-flag 표, 진단 다수결
